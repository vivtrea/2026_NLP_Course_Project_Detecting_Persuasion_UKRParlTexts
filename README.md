# 2026_NLP_Course_Project_Detecting_Persuasion_UKRParlTexts
Course project on Detecting and Classifying Persuasion Techniques in Ukrainian Parlamentary Texts

# Team 
Roman Pempus, Iryna Svyrydenko, Andrii Hovorov

## Data

The Polish data were taken from the
[SlavicPersuasionTechniques](https://github.com/SlavicNLP/SlavicPersuasionTechniques)
repository, specifically `data/PL/train.csv`.

The corpus is described in:

Piskorski, J., Dimitrov, D. I., Ernst, M., Haneczok, J., Marcinczuk, M.,
Modzelewski, A., & Yangarber, R. (2026).
A Corpus of Persuasion Techniques in Slavic Languages.
Proceedings of LREC 2026, 3599–3616.
https://doi.org/10.63317/46rmmqosdrgt
